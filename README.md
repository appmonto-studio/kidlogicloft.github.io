# kidlogicloft.github.io
Landing page and app portfolio repository.

## Generated landing pages

The English, German, and Spanish landing pages share one structure and are
generated by `tools/generate_home.py`. Edit the localized copy and template in
that file, then run:

```bash
python3 tools/generate_home.py
```

App-detail and privacy pages remain hand-written, but use the same local
`assets/site.css` and `assets/site.js` family shell.
